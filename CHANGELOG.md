# Changelog

## 1.0.0 · 2026-11-24

- Compare local CSV and TSV exports by one key or a combination of columns.
- Inspect exact before/after values, additions, removals and schema changes. Search across changed fields and page through results.
- Read UTF-8 and BOM-marked UTF-16 automatically and select Windows-1251 explicitly.
- Report ambiguous or blank identifiers by source and record number.
- Export a full, formula-guarded CSV independent of the current filter.
- Includes English and Russian, light and dark themes, a warehouse tutorial, portable HTML and an unsigned per-user Windows installer.
