# TallyRill design system

TallyRill uses an editorial title above a compact comparison workspace. The three staggered bars in the mark refer to records of different lengths. The same motif appears in the introductory panel. Data remains the primary visual element in the report.

Georgia provides the large title and count numerals. Inter, Segoe UI and the system sans serif stack handle control labels and exact text in tables. The fonts come from the device. The A/B markers, status names and before/after headings carry meaning alongside color. Controls use the same radius, border and focus treatment in both themes.

A centered 1080px workspace uses paired source panels on desktop and stacks them below 680px. The statistics grid becomes two by two below 440px. Browser zoom, relative font sizes, explicit text labels, native checkboxes, select menus and the live status message support keyboard and magnification users. Reduced-motion settings turn off transitions.

English and Russian use the same layout and dictionary keys. File names, headers and values retain their original spelling. The screenshots in media show both themes with real synthetic data.
